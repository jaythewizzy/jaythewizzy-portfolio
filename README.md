# JaytheWizzy — Portfolio & Creative Ecosystem

A multi-page static website for JaytheWizzy / Stephen Omojola.

## Pages
- `index.html` — Home
- `about.html` — About and background
- `studio.html` — Creative and technology practice
- `projects.html` — Software products and ventures
- `games.html` — Game projects
- `media.html` — Music, writing and future screen work
- `contact.html` — Email and WhatsApp contact options

## Stack
Plain HTML, CSS and JavaScript. No build step, package manager or environment variables required.

## Local preview
Open `index.html` in a browser, or run a local static server from this directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Connected to Vercel through GitHub. Push commits to `main` to trigger a production deployment.
