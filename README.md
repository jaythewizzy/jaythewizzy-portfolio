# Stephen Omojola portfolio

Static site, no build step.

- `index.html` is the whole page (styles and script inline).
- `assets/profile.jpg`: add your photo here (square, at least 400px). Until then the page shows your initials.
- `stephen-omojola-cv.pdf`: your CV.
- Domain: `index.html` currently points its canonical and social tags at https://jaythewizzy.com/. Search and replace that if you change domains.

Deploy: push this folder to a GitHub repo, import it in Vercel (framework preset "Other"), then add your domain under Settings > Domains.
