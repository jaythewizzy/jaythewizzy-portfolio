# Navigation & readability update

- Reduced the desktop primary navigation to seven destinations: Home, Technology, Play, Work, Investors, About and Contact.
- Play groups Apps, Games and Developer Platforms. Work groups Projects, Studio and Media & Storytelling.
- Dropdowns support mouse hover, keyboard focus, native click/tap disclosure, and close on route change, outside click, scroll or Escape.
- The Developer Platforms page now also links directly to the Apps and Games catalogues.
- Technology stack pills are now larger, bolder and more legible on the Technology page and app/project detail pages.
- Detail facts and supporting copy have been increased modestly for readability.
- Existing page routes, branding, color themes, content and store/publisher relationships are unchanged.

## Validation

TSX syntax and CSS parsing were checked in the patch-generation environment. Run `npm run typecheck` and `npm run build` in the project before committing.
